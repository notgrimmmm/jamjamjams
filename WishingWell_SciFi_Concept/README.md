# rblgame template

This is a template for making games using the RBL Engine GDX project. 
The template has the engine as a dependency.

Change the map bsp, add custom scriptors, and lots of other things.
See documentation.

## Gradle
[![](https://jitpack.io/v/notgrimmmm/rbl_engine_gdx.svg)](https://jitpack.io/#notgrimmmm/rbl_engine_gdx)

Recommended use is just leave it as the main branch snapshot

` implementation 'com.github.notgrimmmm.rbl_engine_gdx:core:main-SNAPSHOT' `

You can change the version if desired, check the releases and change it accordingly

` implementation 'com.github.notgrimmmm.rbl_engine_gdx:core:v1.0.7' `
